# Commit plan

This is a suggested milestone plan for a two-member team. It is designed to produce around 10-12 meaningful commits while respecting the requirement of at least two hours between commits.

1. Scaffold project structure and README draft.
2. Add formal design docs and architecture overview.
3. Define data models and configuration schema.
4. Implement regex extraction patterns and sample data.
5. Implement extraction module with JSON serialization.
6. Add lexicon and normalization strategy documentation.
7. Implement FST layer for canonical mapping and examples.
8. Build profile configuration files and automata stubs.
9. Implement classifier and profile matching logic.
10. Create textX grammar and parser scaffolding.
11. Add DSL validation, generator, and HTML visualizer.
12. Add end-to-end tests, smoke pipeline, and final review.

## Suggested role split

- Person A: scaffolding, docs, extraction, CLI, testing.
- Person B: formalization, automata, normalization, DSL grammar, report generation.

## Deadline

Deadline: 11 October 2026.

## Notes

The exact time gaps between commits should be enforced when the team actually develops the repository, but this doc serves as a skeleton for planning and review.
