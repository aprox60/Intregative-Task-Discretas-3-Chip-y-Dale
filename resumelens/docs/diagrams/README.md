# Diagrams

Formal definitions and Mermaid diagrams of the formal models. GitHub renders the diagrams directly.

These files are generated from the pyformlang objects. Don't edit them by hand; run this from the `resumelens` folder instead:

```bash
python -m resumelens.docs_export
```

- `transducers/`: the preprocessing transducer and one transducer per technical category (stage 2).
