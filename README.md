# Integrative Task 1 – Computación y Estructuras Discretas III (2026-2)

**Team Chip y Dale:** Ivan Quintero Sanchez, Valeria Valencia

This repository contains **ResumeLens**, a résumé-screening system built with formal language models: regular expressions, finite-state transducers, finite automata and a context-free grammar (textX DSL).

The project is in the [`resumelens/`](resumelens/) folder. See [resumelens/README.md](resumelens/README.md) for setup, usage, tests and documentation.

Quick start:

```bash
cd resumelens
```

```bash
pip install -r requirements.txt
```

```bash
pip install -e .
```

```bash
python -m resumelens
```
